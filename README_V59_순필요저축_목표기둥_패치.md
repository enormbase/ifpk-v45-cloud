# V59 후속 패치 · 순필요저축 목표기둥

기준: V59 웹사이트 + 2026-11부터 시작되는 4대 목적저축 실행 기록.

## 변경 범위
- `docs/index.html`: 주택·자동차·해외여행·은퇴 네 목표 기둥의 '전체 목표일 필요자금' 표기를 '순필요저축 목표액'으로 변경. 진행률은 신규 납입금만 사용.
- `docs/js/v59_net_goal_progress.js`: 신규 저축액 출처별 누적 장부(표시용). 기적립금의 목표일 미래가치를 분모에서 차감하고, 2026.11 이후 확정 신규 저축금의 목표일 미래가치를 분자로 비교. 이미 확정한 납입액과 과거 실적 당시 금리를 반영. 월 납입 시점은 월말(수익 후 입금)으로 기존 V55 엔진과 동일.
- `tests/test_v59_net_progress.py`, `tests/run_v59_net_progress_tests.js`: 최초 0%, 11월 마감, 0원 납입, 금리 변경, 과거 입력 정정, 미확정 예정 입금 제외 검증.
- `tests/test_v501_site.py`: 이전에 이미 제공한 V59 기준 테스트를 포함. 삭제한 '6개월 재설계 · 6개 분야 변경 전후 검토' 화면을 요구하지 않으며, 고급 검증 메뉴는 유지하도록 확인.

- 신규/기존 주담대, 연금·은퇴자금 산출, 소비·물가 계산 엔진
- GitHub Actions와 경제지표 수집기·Supabase·Google Sheets

## 배포 방법
압축을 풀어 `docs/`, `tests/` 경로를 그대로 GitHub 저장소 루트에 올리고 기존 파일을 덮어씁니다. `docs/js/v59_net_goal_progress.js`는 신규 파일이므로 반드시 함께 업로드해야 합니다. 기존 수집기나 설정 파일은 삭제하지 않습니다.

## 확인 사항
- 목표자금 총액은 기존 계산 엔진에 기적립금을 그대로 유지합니다. 별도 은행계좌를 만드는 기능이 아닙니다.
- 신규 납입금에 대한 목표일까지의 미래가치는 현재 적용 수익률 가정에 따라 달라질 수 있습니다. 투입 전부터 확정 수익이 발생했다는 뜻이 아닙니다.
- 이미 저장한 월별 기록은 기존 브라우저의 같은 URL과 저장소에 남습니다. HTML 미리보기는 저장공간/지표 연결이 별도이므로 실사용 사이트와는 기록이 별도로 보일 수 있습니다.
