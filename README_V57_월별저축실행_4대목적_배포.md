# IFPK V57 · 4대 목적저축 동시 실행 / 수동 월마감 / 롤링 재계산

기준: V56 전체요약 타임라인 + V55 통합 월별 저축 배분 엔진. **기존 은퇴자산/대출/연금 원장은 수정하지 않았습니다.** 11월 12일 구글시트 기준 계산 스냅샷을 유지합니다.

## 고객이 보는 동작

1. 전체요약의 `우리 가족의 저축 실행 현황`에 **주택·자동차·해외여행·은퇴가 동시에 표시**됩니다(PC 2×2, 모바일 세로). 각 카드의 월별 필요저축액 막대에는 사람 캐릭터가 있고, 현재월+향후 3~4개월+목표시점이 표시됩니다.
2. 월별 **필요저축액**과 우선순위/저축여력을 고려한 **권장 배정액**을 별도 표시합니다. 캐릭터의 이동은 목표 달성률이 아닌 **해당 월 실적 마감 여부**에 따릅니다.
3. 실제 저축액은 고객이 주택/자동차/여행/은퇴 별로 자유롭게 입력합니다. 목표보다 적거나, 많거나, **0원이어도** 체크할 수 있습니다.
4. 네 목표의 실적 확인을 모두 체크하면 **동시에 다음 달로 이동**하며, 원래 필요한 목표금액·실제 적립잔액·남은 개월·저축수익률·검증된 신규 경제지표를 적용해 목적별 미래 월 필요저축액을 재역산합니다. 우선순위 주택(감액) → 자동차(정액) → 해외여행(정액) → 은퇴(증액)는 현행 기본값이며 고객정보에서 변경 가능.
5. 목표일이 지나 완료된 목적은 이후 월 체크 대상에서 제외됩니다. 새로 나온 월이 실제 달력의 미래라면 가이드라인만 보고, 아직 실제 저축 내역을 확정하지는 못하게 합니다.
6. 마감한 과거 월의 실적을 확인하거나, **직전 월을 다시 열어 수정**할 수 있습니다. 실제 납입액 합계가 저축가능액을 초과한 경우 별도 조달 경고를 보여줍니다.
7. 전체요약의 `매달, 우리 가족 저축계획을 다시 확인해요` 안내에 있던 장황한 미승인·미연결 문구는 짧은 예상금액 안내문으로 바꿨습니다. 세부 한계는 검증 설명과 기록 도움말에 유지했습니다.

## 가장 중요한 운영 한계

- **저장 범위**: 현재 V57 실적 확인과 월 이동 이력은 접속한 **브라우저의 localStorage**에 저장됩니다. 다른 기기와 자동 동기화하지 않습니다. 쿠키·사이트 데이터를 지우면 소실될 수 있습니다.
- **공식 데이터 연동**: 검증된 신규 공개 경제지표를 읽는 기존 공개 원장 연동은 유지하지만, 해당 브라우저의 실적을 **Supabase 고객 계정 또는 Google Sheets로 자동 기록하는 서버 기능은 아직 구현하지 않았습니다**. 실제 은행계좌 자동확인, 신원확인, 고객의 공식 계획 승인도 미연결입니다.
- **공식 계산과 전망의 구분**: 월별 V55/V57은 고객 입력을 반영한 실행 전망이고, 기존 V52 677개월 장부 및 검산 기록은 별도로 보존됩니다. 두 모델 전체가 공식적으로 재대사·승인됐다고 주장하지 않습니다.
- 사용자 입력으로 경제지표 CPI·금리 등 변경 시, V55의 검증된 재계산 범위에서만 반영합니다. 부동산 대출규제/미래 대출규모 재승인 같은 별도 검증이 필요한 항목은 확정값이라고 말하지 않습니다.
- 이 프로젝트의 구글시트 `11월12일`에는 이미 `저축실행_월별` 실납입 입력 열·4대 목적/우선순위·감액/정액/증액 계산이 존재하여 **이번에는 시트의 수식을 변경하지 않았습니다**. 월확인 체크의 백엔드 양방향 동기화는 추후 과제입니다.

## GitHub 업로드

1. ZIP 파일을 내려받아 압축을 해제합니다.
2. `https://github.com/enormbase/ifpk-v45-cloud`의 `Code → Add file → Upload files`에서 아래 상대 경로를 보존해 **동일 경로 파일을 덮어쓰기** 합니다.
   - `docs/index.html` (V57 웹사이트)
   - `docs/js/v57_monthly_close.js` (독립 함수/회귀검사 파일; 웹 실행에는 동일 로직이 인라인으로 포함됨)
   - `docs/CHANGELOG_KO.md`
   - `tests/` 아래 ZIP의 테스트 업데이트
   - 루트 `test_v53_runtime.js` (이전 회귀 테스트의 V57 모듈 대응)
3. `main`에 커밋합니다. 권장 메시지: `feat: V57 four-goal monthly execution and rolling close`.
4. `Actions → IFPK | Website deploy (reuse last verified indicators)`가 `Success`인지 확인하고 https://enormbase.github.io/ifpk-v45-cloud/ 에서 **Ctrl+Shift+R** 로 확인하세요.
5. 기존 `.github/workflows`, collector, Supabase 설정과 공개지표 데이터 JSON은 ZIP에 들어 있지 않으며 변경하지 않습니다.
