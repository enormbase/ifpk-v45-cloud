# IFPK V59 | 4대 목적저축 실행 + 월별 경제지표 롤링

기준: V58 웹사이트 + 2026.11.12 구글시트 최초 설계 스냅샷. 사이트 상단 버전 V59.

## 변경사항
1. 주택·자동차·해외여행·은퇴의 **실제 저축액 입력+실적 확인** 체크 4개를 모두 마쳐도 자동으로 이동하지 않습니다. 아래 **「다음 달 계획 계산하고 이동하기」** 버튼이 활성화된 후 직접 클릭해야 다음 달로 이동합니다.
2. V58의 지난달 기록/전체 월별 기록/한 달씩 되돌아가 수정하기/브라우저 저장 키를 유지합니다. 목표액 초과·미달·0원 모두 기록 가능하며, 후속 월의 월 필요저축액과 우선순위별 권장액을 다시 계산합니다.
3. 목적별 최종 목표 기둥에 **기존 적립액과 과거 확정 납입액을 목표일 예상가치로 환산한 자금 준비율**을 표시하고 아래부터 색이 채워집니다. 아직 입력하지 않은 미래 납입액은 준비율에서 제외합니다. 목표기둥에 변화 원인 세부 설명은 넣지 않았습니다.
4. 최신 경제지표 어댑터 `docs/js/v59_economic_adapter.js`를 추가했습니다. 공개 저장 원장 및 검증 가공값 중 지표별 최신 가용값(일반 CPI, 자동차 CPI 3개월 평균, 여행 CPI 12개월 평균, 세후 예금금리 최근 60개월, 신규 주담대 금리 5년 70%/10년 30%, R-ONE 주택지수 5년/10년 CAGR)을 사용합니다. 발표 자료가 없거나 연속기간이 부족하면 마지막 검증값, 없으면 최초 설계 가정을 유지합니다. 지표별 적용 기준월을 화면에 표시합니다.
5. 연결된 부분의 월별 전망 갱신: 소비/양육비 및 은퇴후 생활비(일반 CPI), 자동차 할부상환(자동차 CPI), 여행 목표액(여행 CPI), 목적저축 수익률(예금금리), 이사후 대출상환(주담대금리), 주택 갈아타기 현금 목표 민감도(R-ONE CAGR). **주택 매각/신규 대출 LTV·DSR/전체 연금/보험/실제 은행계좌까지 모두 재산정한 공식모델은 아닙니다.** 자동차의 자기자금 목표는 기존 2천만원 가정을 유지하고 신차 예상가격/할부부담에 물가 변동을 반영합니다.
6. 분야별 설계의 기본 계산 과정은 **2026.11 최초 기준**을 보존합니다. 소비설계에는 일반소비/자동차/해외여행의 최초 대비 현재 물가 기반 계산 비교가 추가됩니다.
7. 생애현금흐름 상단에 고객이 직접 입력한 과거 실적과 미래 필요저축·권장 배정, 은퇴 후 인출을 반영한 **별도의 월별 롤링 전망**을 제공합니다. 기존 677개월 공식 원안은 접힌 별도 영역에 보존합니다. 일부 대출·연금·현금흐름 요소는 최초 가정값을 유지하므로 공식 승인·완전 재설계로 오해해서는 안 됩니다.
8. 경제지표·설계갱신 화면에서는 6개월/반기 정기 재설계 검토·승인 버튼과 패널을 제거하고, 새 계산용 6개 지표의 상태 및 원자료 그래프를 유지합니다. 다른 탭의 옛 검증 로직이나 시트 자료를 삭제하지는 않습니다.

## 저장과 안전
- 고객 월별 입력기록은 **현재 브라우저의 localStorage에만 저장**됩니다. 기존 키 (`ifpk-v57-shared-monthly-close-v1` 및 `ifpk-v55-savings-local-preview-v1`)를 그대로 사용합니다.
- 다른 PC/브라우저 자동 동기화, Supabase 고객별 실적 저장, 은행 거래 인증, 공식 재무계획 자동승인은 구현하지 않았습니다.
- 브라우저 저장정보를 지우지 마세요. 미래월의 기록은 실제 납입확인이 아닌 체험 시뮬레이션으로 표시됩니다.
- **구글시트는 수정하지 않았습니다.** `2026.11` 최초 산출 근거는 보존하고 V59 동적 엔진의 재계산은 JS에서 수행합니다.
- 클라우드 지표는 GitHub Pages에 배포된 `./data/status.json`, `./data/public_indicators.json`에 의존합니다. 단독 HTML 미리보기에서는 공식 원장에 접근하지 못하므로 최초 가정으로 표시될 수 있습니다.
