# V58 월별 실행 오류 수정 및 지난달 기록 강화

- V57에서 달력의 현재월보다 미래인 12월 실행 입력·실적 확인 버튼이 비활성화되는 조건 수정.
- 아직 도래하지 않은 달은 시뮬레이션 입력으로 명시하며, 고객의 실제 납입으로 인증하지 않음.
- 이전 V57의 브라우저 저장 키를 유지하므로 11월 완료 기록/12월 진행 상태를 그대로 이어서 사용.
- 기존에는 접혀 있던 월별 실적 기록을 상단의 지난달 기록으로 이동. 목적별 당시 필요액/권장액/입력액/차액 및 다음 달 필요액 변화 표시. 전체 월별 실적 펼쳐 보기.
- 최근 기록 수정 기능 유지. 마지막 확정월을 열어 정정하면 이후 계획 다시 계산.
- 롤링 계산은 기존 V55 엔진 유지. 실제 납입 차이와 검증된 최신 경제지표 반영. 새 경제지표가 없으면 기준 가정 재사용. 은퇴 필요액은 수익률/잔여기간/계좌잔액에 반응하며 일반 CPI나 예금금리가 자동으로 은퇴 목표자금을 모두 바꾸는 것은 아님.
- 과거에 V57 화면에 입력된 실적을 자동 삭제하거나 Supabase에 기록하지 않음. 브라우저 로컬 저장 방식.
